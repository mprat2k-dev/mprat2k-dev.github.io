# A suspicious Flag

Accela isa recordkeeping system with a few... quirks. One of these are its multiple proprietary scripting frameworks and no-code solutions. these are fine so long as  you don't customize them too much. But of course, $BIG_AGENCY constumized the absoute *CRAP* out of it. This has led to some... creative fixes.

(note for later: debug on expression)

Accela has what are called "Event scripts". These trigger when a certain action occurs. Maybe an Inspection ahs been completed or an Application has beend submitted. There will be an event script that triggers to do... whatever it is you need to do. But, there is no way to pass parameters between event scripts.
So, I was forced to put a flag in a text field in order to pass along data.
Now this is an obvious hack,but AGENCY wants what AGENCY gets.
